# 生成质量与浏览器端评测口径

适配层基线通过后使用本协议扩展评测；本文定义流程，不代表这些评测已经执行。

## 输入集

从五类开始：中文、英文、中英混合、静音、句中停顿。每类先准备至少3条独立短样本，用于检查工具与标注流程；该数量不是统计充分性的承诺。语音来源、参考文本和是否人工核对必须分开记录。参考文本来自TTS提示时，仅能作为合成样本的生成条件。

同一实验固定输入PCM、音色/人物、模型权重与源码版本、推理参数、输入节奏、运行设备及其他模型是否驻留。正式对照使用独立保留的测试样本，不只测调参时反复听过的例子。

静音是数字人驱动探针，不通过ASR强行要求生成回答。分别观测模型生成的静音嘴部运动和浏览器idle切换，两者不是同一现象。

## 输出与人工标注

只保存有权使用的本地输出；原始素材与视频默认放在忽略目录中，不自动进入源码包。对照输出随机编号，标注者先不看模型/优化名称。

每个异常记录：case_id、匿名变体、渲染类型、片段起止秒、问题类别、严重程度、文字说明、标注者和复核状态。
严重程度取0（未观察到）、1（可察觉但不影响理解）、2（持续明显）、3（不可用）。没有看过的片段必须记为未评估，不能填0。

| 维度 | 观察内容 | 适用范围 |
| --- | --- | --- |
| 口型时序 | 开口是否对应声音起点、停顿是否闭口、整段是否明显偏移 | 2D / 3D 分别统计 |
| 口型内容 | 音素变化时嘴部是否有相应变化、是否出现持续错误张闭口 | 需要人工试听；不能仅看振幅相关性 |
| 时序连续 | 唇部/头部突跳、分块边界、重复帧和抖动 | 与帧到达间隔和播放丢帧分开分析 |
| 身份与外观 | 人脸身份改变、纹理漂移、牙齿/脸部伪影 | 2D；无纹理3D不使用相同身份指标 |
| 头姿与表情 | 头姿不连续、表情突变、idle与说话切换 | 状态切换必须记录切换事件 |

没有同步真人参考的视频，不能报告基于参考的重建误差。自动口型同步评分若依赖预训练模型，先核验其对目标语言、静音和无纹理3D渲染的有效性；不得把模型无效输入产生的数值当作比较依据。

## 浏览器与语音链路计时

- 输入结束：已知测试WAV最后一个语音样本的采集时刻，与VAD确认结束分开。
- 首媒体：浏览器收到可播放的配对媒体时刻。
- 首播放：AudioContext实际安排的首个音频起点；这仍不是扬声器物理出声测量。
- 打断检测：新语音开始、服务端确认打断、浏览器停止已安排音源分别记录。
- 轮次关联：session_id、turn_id、generation、clip_id，明确一轮回复可能有多个clip。

同一浏览器单调时钟计算输入结束到安排播放的延迟。服务端日志单独拆解ASR、LLM、TTS和数字人；未做时钟校准时，不直接用浏览器时间减服务器时间。冷启动、预加载首请求和稳定重复请求分开统计。

## 阶段验收

1. 五类输入均可复验，参考文本核对状态真实记录。
2. 三驱动有配对媒体输出、独立质量观察及失败样本；未通过项明确保留。
3. 两条对话后端有相同任务下的浏览器端延迟与中断记录。
4. 至少定位一个可验证的瓶颈或失败模式，再提出优化假设与对照方案。

只有这些证据具备，才将“第一阶段完整基线”标为完成。单元测试通过和适配层首帧计时均不能替代本阶段。
