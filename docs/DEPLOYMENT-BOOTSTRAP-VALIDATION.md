# 统一检查与启动入口验收

2026-09-20。本轮针对应用部署入口，复用已经准备好的独立模型服务。

## 验证范围

- 从导出源码包解压到干净目录，逐文件核对发布清单 SHA-256；不复制运行时配置、凭据、会话、idle 或模型权重。
- 只创建最小 `.env`：MiniCPM、FlashHead 本机地址与明确的 NLTK 资源目录；使用已有、与锁文件一致的应用解释器。
- 从项目目录之外执行 `demo.py check --backend minicpm --profile flashhead --require-vision --json`，检查通过。
- 使用同一组参数执行 `demo.py run`，在空闲本机端口启动独立临时应用；`/avatar` 返回页面，`/avatar/providers` 返回默认角色 FlashHead、默认后端 MiniCPM，视觉能力可用。
- 临时进程退出并回收；现有应用与 GPU 模型进程保持运行。
- 修复后全套 269 项应用测试、9 个前端测试文件通过。
- 自动测试覆盖无效配置、不完整应用环境、端口占用、所选链路、角色音色、云端未验证提示、DINet 检查边界、私密信息不回显、HTTP 响应大小/重定向/截断/超时，以及配置检查与实际启动的一致性。

默认驱动和默认角色是不同字段：选择 FlashHead 角色后，页面会按角色选择它的驱动；无须改写部署文件。
