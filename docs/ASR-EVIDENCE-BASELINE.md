参考内容是生成语音时使用的文字，尚未经过人工听写。这里衡量的是模型输出与合成提示词的差异，**不是已验证真实语音上的 CER，更不是“识别准确率 100%”**。合成语音可能与提示词发音不同，模型和 TTS 的影响无法由这组数据单独区分。

样本表明术语提示值得继续验证；只有三个样本、每种配置每条一次，不能宣称普遍提升、模型排名或统计显著性。未完整保留模型修订号、完整术语配置和请求时音频哈希，因此复现范围是文本评分，而非相同模型请求与精确性能。

例如历史无提示结果中的 `MiniPAMO` 与目标 `MiniCPM-o` 不同；1.7B 有提示结果在本样本中匹配。0.6B 有提示结果仍将 `Pipecat` 写为 `PipCat`。原样文本见输入文件，未做事后纠错。

## 离线复算

从仓库根目录执行，Python 标准库即可：

```bash
python3 evaluation/asr_scoring.py \
  docs/benchmarks/2026-10-10-asr-historical-input.json \
  --output /tmp/voxastage-asr-score.json
python3 -m unittest discover -s evaluation -p 'test_asr_scoring.py'
```

- [评分输入](benchmarks/2026-10-10-asr-historical-input.json)：12 条原始识别文字与参考来源；不含录音、机器路径或服务地址。
- [可重算结果](benchmarks/2026-10-10-asr-historical-results.json)：逐样本差异与分组统计。
- [来源记录](benchmarks/2026-10-10-asr-historical-provenance.json)：两份历史日志摘要、当前三个 WAV 的哈希与格式、评分输入摘要。

当前 WAV 哈希是本轮库存校验，不证明历史请求发送的字节与其相同。三段当前音频长度为 7.3386875、7.04、4.864 秒，与历史响应记录一致；仅凭时长相同仍不能证明字节相同。原始录音不随源码分发。

本轮验证：22 项评测测试通过，其中新增评分测试 10 项；源码导出包含全部评分代码与纯文本证据，独立解包后 10 项测试通过，重算 JSON 与存档报告一致。独立审查修复了部分失败时分母口径的歧义；未新增模型推理、人工质量评分或物理设备验证。

## 指标契约

输入为记录数组，每条必须含 `case_id`、`variant`、`reference`、`reference_kind`、`transcript_reviewed`、`status` 和成功结果的 `text`。所有配置必须有完全相同的样本集合和参考内容；重复样本、缺失结果、参考来源不一致会失败。重复运行应使用独立且各配置共同的样本 ID。

`reference_kind=synthesis_prompt` 必须搭配 `transcript_reviewed=false`，报告提示词差异率；实际人工听写后使用 `human_transcript` 与 `true`，单独报告 normalized CER。来源标记依赖数据提供者真实填写，程序无法证明听写发生过。

归一化顺序为 Unicode NFKC、casefold、去空白与 Unicode 标点，其他符号保留。使用 Unicode 字符编辑距离，插入、删除、替换的代价都是 1；按总参考字符加权，不取每条百分比的平均。英文也是字符单位，**不是英文 WER**；大小写、标点和空格错误不会被这个指标惩罚，也不会改写拼写、数字或术语。结果可能大于 100%。

`status=error` 保留在尝试数中，但没有可评分输出，不伪造空转写。成功返回空字符串则是真实空转写，非空参考按删除计分。报告分别记录失败数、参考字符覆盖率和 `complete`；`rate_scope` 明确文本差异率只统计成功且参考非空的子集。存在失败时不可仅用 rate 给配置排名，CLI 保存部分报告后退出码为 1。无有效结果则 rate 为 null。

归一化后参考为空的样本单独报告非空输出数与插入字符数，不掺入非空参考的 CER 分母。该分组统计仅针对成功返回的空参考样本，失败数和整体完整性仍另外保留。

## 后续验收

新采集使用[固定输入请求采集器](ASR-REQUEST-CAPTURE.md)，保存实际请求字节哈希和术语配置、区分预热与正式请求、保留失败。模型未报告的版本与设置保持未知。

固定更广的中文、英文、中英混合、静音与停顿样本；人工核对实际说话内容后，使用相同输入哈希、模型修订号及完整推理配置重跑。真实麦克风集与合成集分开报告。延迟应重新采集并明确起止点，不能拿本次历史服务内部耗时作为当前端到端或物理声学时延。
