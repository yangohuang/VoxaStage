# 视觉／语音输入对照工具

`evaluation/multimodal.py`对同一问题、同一图片与同一原始语音串行运行四种输入条件。它记录worker输出与失败，**不自动认定回答正确**。当前只完成工具及模拟后端测试，真实视觉模型实验尚未运行。

| 条件 | 提交给模型的内容 | 检查目的 |
| --- | --- | --- |
| `audio_only` | 原始问题语音，不提供图片 | 缺少视觉证据时是否承认不知道，避免编造画面 |
| `image_only` | 图片和固定的“请简短描述画面。” | 基础画面描述；没有提供定向问题 |
| `image_text` | 图片和问题的文字版本 | 排除语音理解变量后的参考条件 |
| `image_audio` | 图片和同一原始问题语音 | 联合输入下能否按问题理解画面 |

四种条件的信息不同，不能把“仅语音看不到图”按普通错误累计后宣布联合输入更准确，也不能将通用描述与定向问答的遵循率混算。图片标识使用中性编号，参考答案与输入文件名不提交给模型。

## 输入清单

准备同目录中的静态JPEG/PNG和16kHz单声道PCM16 WAV。图片最多256KiB、1024×1024；语音最多30秒。清单支持1–20条case，不允许文件逃出清单目录；文件内容必须匹配SHA256。例子中的摘要需替换为实际文件摘要：

```json
{
  "version": 1,
  "cases": [{
    "id": "spatial-01",
    "image": "scene-01.png",
    "image_sha256": "文件的SHA256",
    "audio": "question.wav",
    "audio_sha256": "文件的SHA256",
    "question_text": "请说出图中左边物体的颜色和形状。",
    "transcript_reviewed": false,
    "source": "synthetic",
    "expected_facts": ["左边是红色圆形", "右边是蓝色方形"]
  }]
}
```

`question_text`应与问题语音对应；未经真实听写核对，`transcript_reviewed`保持false。`source`标记问题语音来自合成或真人。`expected_facts`用于后续独立判断，不进入任何模型请求。两张简单几何图只能作为能力探针，不能替代多场景视觉数据集。

## 运行

只连接已获授权且明确启用视觉的worker。运行前检查`ready`与`capabilities.image_input`；模型名称按worker自报保存，不能当作模型文件版本的证明。

```bash
.venv/bin/python evaluation/multimodal.py \
  --manifest /path/to/cases.json \
  --url http://127.0.0.1:18201 \
  --output artifacts/multimodal-run-01 \
  --rounds 3 --voice female --save-audio
```

输出目录必须全新，避免覆盖旧失败。一次图片+文字预热单列，之后按case与轮次轮换四种条件的先后顺序；这是确定性轮换，不是随机化试验，少于四轮也不声称完全平衡顺序。每次请求均为独立单轮，不借用上一条件的回答作为模型历史。

报告记录清单原始字节、各输入文件、原PCM、规范化请求、评测代码的摘要；每轮保存返回文字、首文字/首音频到达时间、总耗时、PCM样本数和摘要。只在指定`--save-audio`时把生成WAV保存在本地输出目录。URL、图片base64和输入语音不写入报告。

输入数据在加载时校验并固定，清单摘要对应同一份原始字节。单轮错误保留类型及已产生的部分输出，关闭响应后继续预定轮次；失败保留在正式分母中。总状态同时考虑预热与正式请求；任一请求失败时命令非零退出。超时包含排队/重试与响应，不能当作纯模型计算时间。

## 结果复核

`status: passed`只表示该轮通过流协议及有界输出检查。`semantic_assessment`初始为null；未判读答案的次数不会计入语义正确率。复核时按报告中的输入摘要与参考事实检查原图、问题和回答，保留判断来源、理由及响应摘要；以下指标分别报告：

- 图片描述是否与可见事实相符；不能把漏答定向问题算在未收到该问题的通用描述条件中。
- 图文与图音是否回答同一个问题，是否混淆空间位置、形状或颜色。
- 仅语音条件是否承认没有图像，是否无依据猜测具体视觉属性。
- 失败、超时、无语音输出各自计数；不从分母中删除。

本工具测量的是单轮worker边界，不测麦克风、浏览器或数字人嘴型；多轮前后画面指代、第三图裁剪和迟到结果已有会话契约测试，但仍需真实模型与浏览器组合验收。生成音频的实际听感另行复核。

```bash
.venv/bin/python -m unittest discover -s evaluation -p 'test_multimodal.py'
```

测试使用注入后端，并在报告中标记`execution: injected_backend`，不能作为真实模型成绩。HTTP模式同样仅说明经过网络worker接口；要证明真实推理，仍须另存服务版本、启动配置及推理日志。

7项本地测试覆盖输入校验、请求条件、顺序与失败分母、超时清理、清单读取快照，以及使用模拟HTTP传输的能力检查、NDJSON截断和生成WAV格式。后两项经过实际客户端解析器，响应仍由测试替身提供；它们不涉及真实推理。
