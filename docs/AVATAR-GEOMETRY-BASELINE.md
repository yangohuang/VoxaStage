# 3D 结构与运动数值基线 · 2026-09-19

对既有 StreamingTalker 输出的15段、1366帧逐帧检查。每帧5023个顶点、9976个三角形；原捕获哈希、PCM和时间戳验证通过。没有重新调用模型，也没有给感知质量打分。

## 结果

所有样片拓扑均无重复面（忽略绕序）、重复索引面或未引用顶点。以每段首帧包围盒对角线 D 归一化，所有帧的三角形面积 / D² 均大于 `1e-12`，没有数值近退化面；全体最小值约 `1.60e-9`。这是数值检查阈值，不是视觉合格线，不检测自相交、法线朝向、身份或嘴部解剖合理性。

相邻帧指标为全部顶点欧氏位移的均方根除以 D。下表均值按帧对数量加权；最大值是类别内最大的单帧对。单位为 D 的百分比，不能当作错误率。

| 输入类别 | 片段 / 帧数 | 平均相邻位移 | 最大相邻位移 |
| --- | ---: | ---: | ---: |
| 中文 | 3 / 212 | 0.07894% | 0.30101% |
| 英文 | 3 / 230 | 0.07692% | 0.30006% |
| 中英混合 | 3 / 257 | 0.08992% | 0.42233% |
| 含插入停顿 | 3 / 487 | 0.07265% | 0.30101% |
| 全静音 | 3 / 180 | 0.03022% | 0.29237% |

`silence-01`、`silence-02`最大位移均为零起始编号的第58→59帧（目标PTS约1.967秒）。静音也会运动；该观察只提供动态复核定位，尚不能区分自然待机、姿态变化或不期望的动作，不能声称为异常张嘴或分块边界伪影。没有嘴部区域标注，整网格统计也可能掩盖局部问题。含停顿样片按整段统计，没有把语音段混算成纯静音指标。

## 复现与验证

```bash
.venv/bin/python -m unittest evaluation.test_geometry_audit
.venv/bin/python -m evaluation.geometry_audit \
  --captures artifacts/quality-captures \
  --output artifacts/geometry-audit/results.json
```

复用[捕获与复核格式](AVATAR-QUALITY-REVIEW.md)，只测其中成功的3D样片；输出文件要求尚不存在，防止覆盖旧证据。保留每帧最小面积、近退化数量和前五运动峰值的帧对/PTS，逐段记录捕获fingerprint及检查代码SHA。原始音视频和网格不进入源码包。

5项合成测试覆盖已知三角形、静止、刚性平移、尺度不变性、峰值定位、拓扑问题、单帧以及无效几何/时钟；审查发现漏记逐帧面积，已补对应失败→通过验证。全部15段运动均值还与原捕获记录交叉核算，恢复到原始单位后的误差小于 `1e-12`。
