# 3D 捕获结构检查

补充现有基线的数值检查，不新增服务、不调用模型、不替代动态人工复核。读取已捕获的 3D 拓扑与逐帧顶点，复用捕获哈希和尺寸验证。

1. 用已知三角形、刚性平移、尺度变化和退化面写测试；验证面积阈值、运动归一化、峰值帧定位。
2. 每段以首帧包围盒对角线 D 归一化；计算三角形面积 / D²、相邻帧顶点位移 RMS / D。面积不大于 1e-12 的面只标为数值近退化，阈值不表示感知质量。
3. 报告拓扑重复面、重复索引面、未引用顶点、每帧最小面积及变化最大的五个帧对。静音、语音与停顿按原始 case 类别分开，不做跨模型质量排名，不假定分块边界。
4. 在全部已有 3D 捕获上运行，保存输入 fingerprint、检查代码哈希及统计结果。至少人工核算一个合成案例并与原捕获的相邻帧指标交叉检查。
5. 汇总数值发现及局限。第一阶段的人工试听仍单独待验；之后推进已经定位的 DINet 供帧停顿受控实验，不继续扩展评测页面。
