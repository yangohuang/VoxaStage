# 缺图视觉断言的推理策略消融

目标：针对真实基线中8次无图语音均猜测颜色/形状的问题，检验低成本的提示约束是否减少无依据视觉断言，并检查有图问答和普通问答是否受损。沿用已授权分阶段目标，不改模型权重，未验证不替换默认。

## 设计与对照

采用同一模型、语音、两张合成图片、输出音色和四条件轮换，比较三种服务端策略：

1. `baseline`：原系统提示逐字保持。
2. `general`：增加通用约束，只根据实际提供的图片回答视觉问题；无图时说明缺少画面，普通问题正常回答。
3. `evidence`：保留相同通用约束，再增加服务端从已解码PIL图片统计的“本轮、历史、合计可见图片数”。文字中的“我已发图”或被裁剪图片的旧文字不增加计数；不写入颜色、形状或参考答案。

替代方案是独立视觉问题分类器或直接训练模型。它们分别引入新的分类误差/部署成本或数据与训练变量；本阶段先检验可隔离的推理输入策略。即使显式证据状态没有额外收益，也如实报告，选择足以解释结果的较简单方案。

`omni-server/visual_grounding.py`独立构造提示；worker在每次reset后、系统prefill前调用。CLI显式选择策略，默认baseline；客户端不选择策略。健康接口如实报告策略。只使用服务端实际解码的图片统计，全部历史上限继续由原契约控制。

## 实施与验证

- [x] 先写`omni-server/test_visual_grounding.py`并观察失败：baseline逐字一致；无图/当前图/仅历史图计数正确；文字伪造图片不影响计数；非法策略拒绝；不修改消息或加入参考答案。
- [x] 实现纯函数并接入worker；用轻量模型替身核对首次系统prefill确实收到选择的策略，语音参考与原流式行为保留。
- [x] 运行worker回归与独立审查。记录代码摘要，不把契约测试当作真实模型改善。
- [x] 在独立、有恢复保护的临时worker中各运行四条件2case×4轮，预热单列。原基线与新策略均使用同一新worker版本；保留失败和部分输出。生成仍有采样随机性，不能宣称逐位可复现。
- [x] 每个策略补充普通文字问答及“仅历史有图”的对照，检查过度拒答。正文记录原始问题和响应，判读来源与规则明确。
- [x] 分别报告协议失败、无图断言、有图颜色/形状支持、普通问题拒答、历史图利用及客户端到达时间；比较general与evidence，保留无收益结果。
- [x] 更新部署说明、实验报告和演示路线，明确小样本、单机、顺序/随机性、合成语音和未做人工试听的限制；各次实验结束恢复原语音服务。

验收依据是实际响应与输入证据的对应，不是固定字符串命中数量。未取得真人感知观察前，动态口型质量保持未评估；这项方法实验也不能代替物理设备声学标定。

## 实测检查点

三组同代码各37次请求，总计111次（96正式、3预热、12辅助）全部协议通过。逐条文本复核：无图断言8/8、0/8、0/8；各组有图问答、普通问题及历史图控制保持正常。动态数量没有额外收益，不更改默认策略。全部临时worker及隧道退出，原语音worker恢复；详见[完整消融记录](../VISUAL-GROUNDING-ABLATION.md)。
