# 应用容器安装与启动验证计划

执行方式：继续本会话已授权的分阶段部署验证，在独立工作树执行并进行代码/结果审查。

**目标：**从公开源码和原始发行包在独立 Linux 用户空间安装应用，运行现有回归与真实 HTTP 启动检查，为后续组合部署建立可靠入口。

**架构：**应用仍使用 Python 3.11，与 ASR/LLM 的独立模型镜像分离。固定官方基础镜像摘要；保留根目录的 100 个版本锁，不借用宿主已安装包。补充目标平台发行文件 SHA256 清单，构建时禁止 Python 包联网解析。NLTK 资源保持现有安装脚本的 SHA256。验证容器没有 GPU、外部模型地址或开发运行配置。

**边界：**仅安装/启动通过不代表真实会话通过；组合部署、其他 worker、全新 GPU 主机及人工音画验收仍属于原目标。
