# 应用事实提示与工具链路复核

目的：上一轮裸词表消融不等于日常应用提示。对同一Qwen服务，用现有bot.SYSTEM、LocalBackend、AgentRuntime及ToolRegistry验证六条预先指定输入，记录工具实际执行与最终回答。现有结构化事实、检索指令、180字提示和多次生成均与上一轮控制条件不同，不作单因素优劣或性能比较。

- 固定3条历史复杂题、1条项目模块归属题、1条视觉上下文题、1条计算控制，rubric与输入在运行前提交。
- 静态解析bot.SYSTEM字面量，避免导入启动应用；重用原Agent执行器、原本地后端及只读工具。清单标识为部署源码探针，不宣称经过浏览器、ASR或TTS。
- 每题前检查真实应用active_sessions=0、LLM ready且不busy；有占用即停。工具仅用现有受限目录，不改服务和提示。
- 保留每次模型输入、流式输出、实际工具调用与结果、最终文本及单调时钟耗时。记录代码和检索文档SHA256，失败也落盘。
- 基于事先rubric逐题检查；助手审查和真人反馈分开，不把协议成功计为语义通过。发现的新失败先报告、定位，再决定是否修改。
- 导出、脱敏与独立审查通过后提交报告；原四阶段的人工/声学/独立GPU部署门槛保持未完成。
