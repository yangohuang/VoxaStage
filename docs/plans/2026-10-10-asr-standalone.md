# Qwen ASR 独立部署计划

目标：从公开源码在 Linux x86_64 / Python 3.12 新虚拟环境重建现有 Qwen3-ASR-0.6B worker，并执行相同固定输入；不继承既有 Conda 包、不改线上服务、不下载权重。

设计：复用根目录 asr_server.py，在 asr-server 提供完整带哈希依赖锁与安装说明。保持已验证的核心推理版本（torch 2.11.0、transformers 4.57.6、qwen-asr 0.0.6），补齐 SDK 声明依赖，由正常解析与 pip check 验证。使用全新环境、单独端口与已有本地可信权重完成推理，结束后回收临时服务。系统驱动与模型文件仍为外部前提，不将本机新环境验证称为空白 GPU 主机验收。

选择完整独立依赖而非共享 Conda overlay，以移除个人目录和隐式依赖；暂不新增容器编排，现有 worker 足以验证这一部署环节。

- [x] 固定依赖输入 asr-server/requirements.in，正常解析完整哈希锁（不使用 --no-deps 绕过缺失依赖）。
- [x] 在新虚拟环境实际安装；运行依赖检查、导入、现有 ASR 协议测试。保留解析/安装失败记录。
- [x] 从公开源码在独立端口启动实际 GPU 模型，固定 15 输入、2 配置、3 轮，验证请求完成及评分；单独记录其环境，不能和旧部署混作相同环境。
- [x] 补可复制命令、环境/权重前提与实测报告；源码导出包含 asr-server 配置文件，独立复算公开证据并通过审查。

交付通过后提交 PR 并合并，合并状态以 GitHub 记录为准。

实际安装与推理是配置变更的主要验收，不新增镜像式测试。不会把安装检查作为人工质量验收，也不会因真实模型不可运行而用假模型填写通过结果。
