# 隔离应用与真实模型组合会话验证

沿用已授权的完整目标和分阶段部署计划。前置证据为 PR29、PR30、PR31 的独立 LLM、ASR 和应用镜像；本阶段连接真实服务，不能把已有单组件通过自动当作组合通过。

## 设计与边界

启动三份已验证镜像：应用、Qwen3-ASR-1.7B、Qwen3-4B NF4。应用通过新建回环端口访问独立模型，TTS 与 StreamingTalker 使用已部署服务。全部服务仅绑定回环；无公网端口、模型切换或其他服务停止。容器使用宿主网络以访问专用 SSH 回环转发，这一网络边界与此前 `--network none` 的单组件检查不同，报告必须写清。

本轮选择当前可用的 3D 服务。DINet/FlashHead 本地端口当前未监听；不以这次 3D 检查替代 2D、视觉输入、浏览器渲染、物理声学或新 GPU 主机验收。播放确认由协议客户端模拟，只证明会话状态与媒体传输，不声称人实际听到了声音。

## 冻结输入与验收

1. 简短文字输入，检查增量文本、音频/网格和完整回复。
2. 既有固定哈希的中英混合合成 WAV，按 20ms 包发送并加尾部静音，检查 ASR 转写、回复与媒体。
3. 较长文字输入，首个媒体包后主动打断，再发送简短恢复请求；新 generation 后不得出现旧 generation 媒体。
4. 关闭并重新连接第 3 项的保存会话（`restore_case` 显式指定），核对中断和恢复回复的历史，再发简短请求，证明新会话可继续。

每项有总期限；任一失败停止整批，保留原事件与检查点，不筛选回复重跑。媒体只公开长度/时间戳/哈希，不发布声音、人物网格或部署地址。合成提示词与实际识别文本分别保留，不声称真人 ASR 精度。
