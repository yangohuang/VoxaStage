# 级联 LLM 独立环境与恢复计划

目标：补齐 Qwen3-4B 级联文本模型的独立依赖安装，恢复已退出的既有服务，以实际流式生成验证可用性。保留既有 NF4 量化、模型权重和 worker；不改 MindTalker，不换模型，不宣称回答质量提升。

现场检查：既有虚拟环境开启 `include-system-site-packages`，核心推理包来自共享 Conda 环境；原本机18311和历史远端18412均无服务，默认配置仍使用本机18311。原 Qwen3-4B 权重存在，本机有显存余量。

选择在新虚拟环境中锁定既有核心版本，比继续继承共享包更可复现；相比同时升级模型或推理框架，减少恢复变量。固定 Python3.12、torch2.11.0、transformers5.12.1、bitsandbytes0.50.2、accelerate1.14.0，闭包解析后逐项校验。

- [x] 解析完整哈希锁，安装到独立环境；确认不继承用户或系统 Python 包，`uv pip check`及导入通过。
- [x] 核对源码、原权重摘要；临时端口运行现有 worker，执行中文/英文/混合技术问题、固定工具生成、长回复流式检查和取消后恢复。失败保留，不将协议成功当作回答质量通过。
- [x] 验证通过后，以持久源码/环境恢复原本机端口；核对健康及应用客户端生成。失败仅清理本次进程/文件。
- [x] 整理部署说明与脱敏证据，执行相关测试、独立审查和公开导出扫描。

该任务验证现有GPU主机上的独立Python环境和服务恢复，不关闭空白GPU主机全模型安装、人工质量或物理设备验收。

## 真实失败后的限定修复

首次21次真实生成中，普通回复、长回复、断流恢复与计算工具通过，但文档检索为空；第二次2请求复现记录了模型生成的整句中文检索参数。原工具仅按空格切词，全文没有该完整句子。新增仅在原检索无命中时启用的中文相邻双字回退，至少命中两个不同双字；保留精确查询优先、英文标识符及原文档权限边界。先复现两项回归失败，再实现与复测；不将此修复称为模型质量提升或通用语义检索。原失败记录保持不变。

摘要定位也出现真实错误回答，最终增加有界密集窗口选择，并修复同分排序与窗口边界回归。277项应用测试、3轮实际检索窄检查通过，详见[报告](../LLM-STANDALONE-VALIDATION.md)。PR发布及合并在收尾时单独核对。
