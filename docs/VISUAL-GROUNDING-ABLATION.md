# 缺图视觉断言：提示策略消融

真实基线发现：用户用语音询问“图中左边物体的颜色和形状”，没有附图时，模型仍编造具体视觉属性。本实验只改变服务端系统提示，检验能否减少这一失败，同时保留有图问答、普通问答和历史图片能力。没有训练模型或修改权重。

## 三种策略

| 策略 | 改变 | 无图系统提示字符数 |
| --- | --- | --- |
| baseline | 原提示逐字保持 | 112 |
| general | 增加“视觉问题只依据实际图片，缺图说明情况；普通问题正常回答” | 197 |
| evidence | 相同通用约束，加上从真实图片对象统计的本轮、历史、合计数量 | 276 |

数量提示不包含颜色、形状或参考答案，也不采信用户文字中的“已发图”声明。每次请求重建上下文，策略进入系统prefill；CLI由部署者选择，HTTP客户端不能改变策略。字符数不是token数。

## 受控运行

三组使用同一提交`55268f943bd7b821c1667421220c665d0c699108`、相同worker/辅助模块摘要、同一固定模型快照、两张合成图片和一句合成语音。按baseline→general→evidence串行启动独立视觉worker，每组均恢复原服务。

每组含1次预热、32次正式请求（2case×4输入条件×4轮），以及4次辅助请求，总计111次真实生成。四条件在组内轮换顺序，但组顺序固定、生成未固定随机种子；不是随机化试验或显著性检验。原始工具语义评分仍为空，下面为单独保存的返回文字与构造参考复核。

## 结果

| 检查 | baseline | general | evidence |
| --- | --- | --- | --- |
| 协议通过（含预热与辅助请求） | 37/37 | 37/37 | 37/37 |
| 无图仍断言具体颜色/形状，越低越好 | 8/8 | 0/8 | 0/8 |
| 图文左侧颜色/形状符合参考 | 8/8 | 8/8 | 8/8 |
| 图音左侧颜色/形状符合参考 | 8/8 | 8/8 | 8/8 |
| 通用图片描述的粗粒度颜色/形状符合 | 8/8 | 8/8 | 8/8 |
| 两个普通问题正常作答 | 2/2 | 2/2 | 2/2 |
| 当前无新图、历史仍有图时正确回答 | 1/1 | 1/1 | 1/1 |

原提示例如回答“图中左边的物体是黄色的，形状像一个圆柱体”；general例如回答“目前没有收到画面，所以无法判断左边物体的颜色和形状”；evidence例如回答“目前还没有收到图片，所以没法描述图中左边物体的颜色和形状”。

辅助问题包括“一加一”和一句话解释语音识别。历史对照先发送红圆图、要求只确认收到，再以实际返回的确认文字构建下一轮；三组确认均未泄漏图片属性。核心33次请求的规范摘要逐项相同；辅助历史使用各组实际确认文字，因此历史请求摘要可以不同，不作为严格同历史输入的延迟比较。evidence回复“好的，收到”未匹配严格的“收到”字段，但不影响该对照的无答案泄漏要求。

通用约束在本探针上已足够；动态图片数量没有显示额外收益。优先提供较简单的`general`作为可选配置，保留`evidence`便于后续研究历史、裁剪与缺失证据。默认仍为baseline，本次没有更改正在使用的语音服务。

## 复现与判读

按[MiniCPM部署说明](../omni-server/README.md)准备固定模型环境。逐组启动同一worker，只修改`--visual-grounding`，确保健康接口报告对应策略；每组独立输出目录：

```bash
# 模型环境：分别以baseline、general、evidence运行，逐组执行
python omni-server/worker.py --model /path/to/pinned-model \
  --port 18201 --vision --visual-grounding general \
  --female-reference /path/to/female.wav

# 应用环境：相同输入清单，四轮；另外两组改输出目录即可
.venv/bin/python evaluation/multimodal.py \
  --manifest /path/to/multimodal-cases.json \
  --url http://127.0.0.1:18201 \
  --output artifacts/grounding-general \
  --rounds 4 --voice female --save-audio
```

输入清单格式见[评测工具说明](MULTIMODAL-EVALUATION.md)。本次两图、WAV及清单另存为本地`reproduction-inputs.zip`，SHA256为`dfbf576638c0aa66909648afe1892dc0801f13b51d2673d17dcd39541b30c81c`；运行素材不随源码归档。使用不同问题或音频时应生成新输入摘要，不能沿用本报告的样本标识作同输入比较。

辅助请求通过同一`POST /generate`接口串行发送，每次保留返回文字与PCM：

1. 独立user文字：“只说一加一的结果。”
2. 独立user文字：“用一句话解释什么是语音识别。”
3. user附第一张图，文字：“只说收到，不要描述图片。”
4. 重放第3步user与实际assistant确认，追加无附图user：“请说出前一张图左边物体的颜色和形状。”

缺图问题中出现任何无依据的具体视觉颜色/形状断言都记失败；承认缺少画面记为适当拒答。有图问答分别核对左侧颜色和形状，通用描述不按定向问题的遵循率评分。普通问题检查是否因无图而过度拒答。不得删除超时、协议失败或不符合预期的回答。

[机器记录](benchmarks/2026-09-19-visual-grounding-ablation.json)保存111次响应、独立语义标记、输入/代码/原始报告摘要和恢复核验。语义复核来源为assistant inspection，没有真人听写、听感或口型质量评分。客户端计时同时记录输出音频时长；回答长度不同，不能把墙钟变化解释为算力加速。

## 未解决的范围

只有一句重复的合成语音、两张简单图片，不能宣称解决通用幻觉。部分general回答要求提供视频，而当前界面只接收图片/快照；这一话术问题仍保留。未测试遮挡、文字OCR、复杂空间关系、长对话或对抗性输入，未证明跨模型适用。用户真实语音、动态口型和物理声学验收仍是独立工作。
