# 本地动态质量复核

`avatar_review.py`把已有输出捕获变成可播放、可逐帧定位的本地复核页。它不调用模型，也不把播放成功当作质量评分。2D使用原始JPEG，3D使用原始顶点与项目现有的正面网格渲染器；音频保持捕获中的PCM。

```mermaid
flowchart LR
  A[已保存的配对输出] --> B[哈希与时钟校验]
  B --> C[匿名样片编号]
  C --> D[连续播放与逐帧查看]
  D --> E[选定时间段和评估维度]
  E --> F[本地标注 JSON]
```

## 启动

先按[输出捕获说明](AVATAR-OUTPUT-CAPTURE.md)准备`captures/<provider>/<case>/`，每个成功目录含`manifest.json`、`metadata.json`、`index.json`、`output.wav`和`frames/`。3D目录另含`topology.npy`。

```bash
.venv/bin/python avatar_review.py \
  --captures artifacts/quality/captures \
  --output artifacts/quality/review \
  --port 18426 --seed 20260919
```

打开`http://127.0.0.1:18426`。远程部署时将此本机端口转发到本地；此工具只绑定回环地址，不提供公网访问。先前的在线对话服务继续独立运行。

同一捕获集与seed使用稳定编号，原始映射只写入本地`key.json`。服务不会覆盖不同捕获集的旧映射，换数据或seed需用新输出目录。页面/API隐藏驱动名称，但人物外观、2D/3D类型仍可能让熟悉数据的人辨认来源，因此不是严格双盲实验。

## 怎么复核

1. 选一段样片。等待预载完成后正常播放，必要时暂停或使用滑块、上一帧/下一帧回看。播放结束不会自动生成分数。
2. 选择实际观察到的时间范围和维度。口型内容必须结合试听；无纹理3D不使用人像身份/外观评分。静音嘴部运动和产品idle切换需分别讨论，此页只重放捕获片段。
3. 填复核者代号、来源、严重程度和现象。人工与自动检查分开记录；未经复核保留“未评估”，不能填0。确认选定时间段后保存。
4. 用“导出JSON”保存记录。标注含样片编号、内容指纹、起止时间、维度、程度、来源和备注；结合本地key还原实验条件。不要把自动化UI测试记录并入质量统计。

每条标注单独持久化，重启可恢复。UTF-8中文和emoji可正常保存、重载。输出目录含人物映射和评价记录，应由部署者自行管理，不自动进入Git或源码包。

## 播放与测量边界

预载一次只保留一个样片。切换会取消旧加载，立即关闭已解码图像，等待仍在解码的结果清理，再开始新样片。允许至多100个成功捕获、单段30秒/1801帧，单段估计解码内存不超过256MiB；损坏的成功捕获拒绝启动，运行中被修改的媒体也不会悄悄播放。

显示帧由`audio.currentTime`和原始PTS选择。离线预载消除了模型供帧间隔，因此不用于判断在线网络/推理卡顿。浏览器渲染繁忙时仍可能跳过显示帧；逐帧定位可检查所有存档帧。3D为固定正面视角、原始网格、项目既有光照，没有真实人像纹理或真人同步参考，不能据此报告身份相似度或参考视频重建误差。

API的标注校验只能确保来源字段和范围有效，不能证明某个人真的完成了试听。质量结论需要实际复核记录；工具测试和数值完整性检查不能替代。

## 2026-09-19 验证

- 原有45个成功捕获（2D 30个、3D 15个，五类各9个）全部通过只读完整性检查。
- 最终三驱动×中文/静音/停顿共9个片段完成真实浏览器播放、结束、首末帧跳转和回看。同一首帧回看后的PNG哈希一致，快速切换保留最新选择。
- 未确认复核、未选择严重程度的保存被拒绝；明确标记为`automated`的UI测试记录完成保存和实际JSON下载，内容与持久化记录一致。该记录只在独立验证目录，不是质量评分，正式复核目录初始为空。
- 15项服务测试、9项新增前端核心测试通过。前端与评测共58项Node测试及1个idle断言脚本通过；独立需求和代码审查完成。

保留了三类失败及修正：自动化脚本不接受裸`await`；WebGL合成后的缓冲读回是透明图，而可见页面正常，改为新绘制后比较；合法Unicode备注经ASCII转义膨胀，导致重启读取超限，改用UTF-8并新增保存→重启回归。需求审查还复现了快速切换的旧解码资源暂留，已加入串行清理及迟到解码回归。

机器记录见[复核工具验证](benchmarks/2026-09-19-quality-review.json)。这证明动态复核材料和标注流程可用；不代表45段都已人工听写、试听或获得口型质量评分，第一阶段整体仍在进行。
